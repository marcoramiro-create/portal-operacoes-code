# Mapa funcional do Portal de Operações

> Documento de referência para orientar o usuário. O menu deve permanecer visualmente limpo, sem descrições extensas em cada item.

## Início

| Item | Finalidade |
|---|---|
| Início | Página inicial e ponto de entrada para as áreas liberadas. |

## Cadastros

| Item | Finalidade |
|---|---|
| Empresas | Cadastro das empresas do grupo. |
| Filiais | Cadastro das filiais vinculadas às empresas. |
| Unidades | Cadastro das unidades e operações. |
| Centros de custo | Classificação organizacional para apropriações e análises. |
| Funcionários | Cadastro de pessoas PF/PJ, documento e cartão/crachá. |
| Fornecedores | Cadastro de parceiros comerciais e dados fiscais. |
| Produtos | Cadastro de itens, atributos e regras de controle. |
| Tipos de produto | Classificação dos tipos de item. |
| Armazéns | Estruturas físicas de estoque. |
| Locais de estoque | Endereços dentro dos armazéns. |
| Empilhadeiras | Cadastro e manutenção de empilhadeiras. |
| Equipamentos da indústria | Cadastro de ativos industriais. |
| Ferramentas | Cadastro e controle de ferramentas. |

## Importações

| Item | Finalidade |
|---|---|
| Fontes Protheus | Importação de SB1, SBZ, referências e demais arquivos do Protheus. |
| Histórico de cargas | Consulta do que foi importado, quando, por qual arquivo e com qual status. |
| Funcionários | Importação em lote do cadastro de pessoas. |
| Fornecedores | Importação em lote de parceiros comerciais. |
| Produtos | Importação em lote de itens e atributos. |
| Custos · Autopeças | Importação da evolução mensal de custos das peças. |
| Custos · Indústria | Importação da evolução mensal de custos industriais. |
| Entradas · Indústria | Importação das entradas de materiais do RM BIS. |
| Evolução de estoque · Indústria | Importação do fechamento mensal do estoque usado na Curva ABC industrial. |

## Operações

| Item | Finalidade |
|---|---|
| Recebimentos NF | Leitura e acompanhamento das notas fiscais recebidas. |
| Requisições | Solicitação de materiais ao almoxarifado. |
| Atendimentos | Separação e entrega dos materiais solicitados. |
| Devoluções | Registro de retornos ao estoque. |
| Movimentações | Registro de entradas, saídas e transferências internas. |
| Estoque | Consulta de saldos por local. |
| Manutenção de ativos | Acompanhamento de equipamentos e ferramentas. |

## Análises

| Item | Finalidade |
|---|---|
| Compras Protheus | Análise de consumo, estoque, giro, cobertura e excesso. |
| Custos · Autopeças | Evolução dos custos cruzada com a Curva de Compras. |
| Custos · Indústria | Evolução dos custos cruzada com a Curva ABC industrial. |
| Curva ABC · Indústria | Cálculo, conferência e acompanhamento da classificação industrial. |

## Administração

| Item | Finalidade |
|---|---|
| Usuários | Aprovação, ativação, inativação e revisão de acessos. |
| Perfis de acesso | Definição das permissões de consultar, administrar e aprovar. |
| Auditoria de cruzamentos | Verificação dos vínculos entre fontes e cadastros. |
| Backlog da auditoria | Acompanhamento das pendências de qualidade e integração. |

## Fluxo recomendado

1. **Cadastros**: conferir empresas, filiais, produtos, fornecedores e pessoas.
2. **Importações**: carregar arquivos e verificar o histórico da carga.
3. **Operações**: executar recebimentos, requisições e movimentações.
4. **Análises**: avaliar compras, custos, estoque e Curva ABC.
5. **Administração**: controlar acessos e qualidade dos cruzamentos.
